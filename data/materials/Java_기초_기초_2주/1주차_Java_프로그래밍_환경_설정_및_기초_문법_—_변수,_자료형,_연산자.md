### 📌 이번 주차 전체 지도
이번 주차는 Java 프로그래밍의 가장 기초적인 토대를 닦는 단계입니다. 지난 주차(학습 전)에는 컴퓨터 사고력의 기반을 다졌다면, 이번에는 JDK 설치부터 시작하여 Java 가상 머신(JVM)의 원리를 파악하고, 데이터를 저장하는 변수와 이를 가공하는 연산자를 배웁니다. 학습 순서는 '개발 환경 설정 → Java 실행 원리 → 변수와 자료형 → 연산자 응용' 순으로 진행되며, 이는 향후 제어문과 객체지향 프로그래밍 학습을 위한 필수 관문입니다.

### 1️⃣ JVM과 컴파일 과정
- **정의**: Java 소스 코드가 어떻게 실행되는지에 대한 프로세스.
- **원리**: `.java` 파일이 `javac`(컴파일러)를 통해 `.class`(바이트코드)로 변환되고, JVM이 이를 실행합니다.
- **예시**: 윈도우에서 작성한 코드가 맥 OS에서도 동일하게 실행되는 원리.
- **주의사항**: JDK(개발도구)와 JRE(실행환경)의 차이를 이해해야 함.
- **시험 포인트**: 'Write Once, Run Anywhere' 개념과 바이트코드(Bytecode)의 역할.

### 2️⃣ 변수 (Variable)
- **정의**: 메모리 공간에 이름을 붙여 데이터를 저장하는 장소.
- **원리**: 선언과 동시에 초기화를 통해 메모리 주소를 할당.
- **예시**: `int age = 25;`
- **주의사항**: 변수 명명 규칙(카멜 케이스, 숫자 시작 금지 등).
- **시험 포인트**: 지역 변수의 초기화 미수행 시 컴파일 에러 발생.

### 3️⃣ 기본 자료형 (Primitive Data Type)
- **정의**: 실제 값을 직접 저장하는 메모리 타입(8종).
- **원리**: 스택(Stack) 영역에 값을 직접 보관.
- **예시**: `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`.
- **주의사항**: 자료형의 크기(범위) 초과 시 오버플로우 발생.
- **시험 포인트**: `int`와 `long`의 차이(L 접미사), `float`와 `double`의 정밀도 차이.

### 4️⃣ 참조 자료형 (Reference Data Type)
- **정의**: 객체의 주소값을 저장하는 타입.
- **원리**: 힙(Heap) 영역에 실제 객체를 생성하고 스택에는 주소만 저장.
- **예시**: `String str = "Hello";`
- **주의사항**: `==` 연산 시 주소값을 비교하므로 주의.
- **시험 포인트**: 참조 자료형의 기본값은 `null`.

### 5️⃣ 연산자 (Operator)
- **정의**: 데이터를 가공하기 위한 기호.
- **원리**: 피연산자의 수에 따라 단항, 이항, 삼항 연산자로 구분.
- **예시**: `a + b`, `a++`, `(a > b) ? 1 : 0`.
- **주의사항**: 논리 연산자 `&&`와 `&`의 차이(Short-circuit evaluation).
- **시험 포인트**: 우선순위(산술 > 관계 > 논리 > 대입).

### 6️⃣ 이스케이프 코드와 포맷팅
- **정의**: 문자열 내 특수 문자를 출력하거나 형식을 지정하는 기법.
- **원리**: `\n`, `\t` 등 백슬래시 조합을 사용.
- **예시**: `System.out.printf("%d", 10);`
- **주의사항**: 백슬래시 자체 출력은 `\\`를 사용해야 함.
- **시험 포인트**: `%d`, `%f`, `%s` 등 포맷 지정자 구분.

### 📊 비교 정리표 1: 기본 vs 참조 자료형
| 구분 | 기본 자료형 | 참조 자료형 |
| :--- | :--- | :--- |
| 저장 대상 | 실제 값(Value) | 메모리 주소(Address) |
| 저장 위치 | 스택(Stack) | 힙(Heap) |
| 개수 | 8개 고정 | 무한(클래스 기반) |
| 기본값 | 지정된 값(0, false 등) | null |

### 📊 비교 정리표 2: 연산자 종류 및 우선순위
| 우선순위 | 종류 | 예시 |
| :--- | :--- | :--- |
| 1 | 단항 | ++, --, !, ~
| 2 | 산술 | *, /, %, +, -
| 3 | 관계 | <, >, ==, !=
| 4 | 논리 | &&, ||
| 5 | 대입 | =, +=, -=

## 연습 퀴즈

1. Java의 메모리 영역 중, 기본 자료형의 값이 실제 저장되는 곳은?
   A. Heap
   B. Stack
   C. Method Area
   D. Register
   정답: B
   관련 키워드: 기본 자료형
   해설: 기본 자료형은 실제 값을 스택(Stack) 영역에 저장하며, 참조 자료형은 힙(Heap) 영역에 객체를 생성하고 스택에는 주소값만을 저장합니다.

2. 다음 중 올바른 변수 명명 규칙이 아닌 것은?
   A. int myAge;
   B. int _score;
   C. int 1stValue;
   D. int $amount;
   정답: C
   관련 키워드: 변수
   해설: 변수명은 숫자로 시작할 수 없습니다. 따라서 1stValue는 컴파일 에러를 발생시킵니다.

3. JVM이 운영체제와 관계없이 Java를 실행할 수 있게 하는 핵심은?
   A. 바이트코드(Bytecode)
   B. JDK
   C. C++ 컴파일러
   D. 메모리 할당기
   정답: A
   관련 키워드: JVM
   해설: Java 소스 코드는 JVM이 이해할 수 있는 바이트코드로 컴파일되며, 운영체제에 상관없이 JVM만 있으면 동일하게 실행됩니다.

4. 다음 연산의 결과로 옳은 것은? `(10 > 5) && (3 == 2)`
   A. true
   B. false
   C. 1
   D. 0
   정답: B
   관련 키워드: 연산자
   해설: true && false는 논리 AND 연산에 의해 결과가 false가 됩니다.

5. Java에서 문자열을 저장하는 적절한 방법은?
   A. char s = 'Hello';
   B. String s = 'Hello';
   C. String s = "Hello";
   D. string s = "Hello";
   정답: C
   관련 키워드: 문자열
   해설: Java의 문자열은 String 클래스를 사용하며, 쌍따옴표(")로 감싸야 합니다. 'string'은 대문자 S로 시작해야 하며, 'char'는 문자 하나만 저장 가능합니다.
