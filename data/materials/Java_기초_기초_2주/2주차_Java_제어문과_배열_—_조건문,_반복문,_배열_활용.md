### 1️⃣ 조건문 (Conditional Statements: if, switch)
- 정의: 특정 조건의 참/거짓 여부에 따라 코드 블록의 실행 여부를 결정하는 구문.
- 원리: 불리언(Boolean) 표현식의 결과에 따라 실행 흐름을 제어함.
- 예시: if (score >= 90) { System.out.println("A학점"); }
- 주의사항: if-else 문에서 조건의 범위가 넓은 것부터 순서대로 작성해야 논리 오류를 방지할 수 있음.
- 시험 포인트: switch문에서 break의 역할(fall-through 방지)과 if-else if-else의 우선순위.

### 2️⃣ 반복문 (Loops: for, while)
- 정의: 동일한 코드를 지정한 횟수나 조건이 만족될 때까지 반복 실행하는 구문.
- 원리: 초기화, 조건식, 증감식을 활용하여 반복 회수를 제어함.
- 예시: for (int i=0; i<10; i++) { System.out.println(i); }
- 주의사항: 무한 루프(Infinite Loop) 발생 가능성을 항상 염두에 두어야 함.
- 시험 포인트: for문과 while문의 적절한 선택 기준(횟수 지정 시 for, 조건 기반 시 while).

### 3️⃣ 배열의 구조 (Array Structure)
- 정의: 같은 자료형의 데이터를 연속된 메모리 공간에 저장하는 자료구조.
- 원리: 0부터 시작하는 인덱스(Index)를 사용하여 특정 요소에 직접 접근(O(1) 속도).
- 예시: int[] nums = new int[5]; nums[0] = 10;
- 주의사항: 배열은 생성 시 크기가 고정되어 있으며, 범위를 벗어난 인덱스 접근 시 ArrayIndexOutOfBoundsException 발생.
- 시험 포인트: 배열의 인덱스는 0부터 시작한다는 점과 .length 속성.

### 4️⃣ 중첩 반복문 (Nested Loops)
- 정의: 반복문 내부에 또 다른 반복문을 선언하여 다차원 데이터를 처리하는 구조.
- 원리: 외부 루프가 1회 회전할 때 내부 루프가 전체를 완료함.
- 예시: 구구단 출력(2단부터 9단까지).
- 주의사항: 중첩이 깊어질수록 성능(시간 복잡도)이 급격히 저하됨.
- 시험 포인트: 내부 루프와 외부 루프의 변수 이름이 겹치지 않도록 주의.

### 5️⃣ 제어 흐름 (Break & Continue)
- 정의: 반복문의 흐름을 강제로 제어하는 예약어.
- 원리: break는 반복문 즉시 탈출, continue는 현재 회차만 건너뜀.
- 예시: if (num == 0) continue; // 0이면 건너뜀.
- 주의사항: 무분별한 사용은 코드 가독성을 해침.
- 시험 포인트: continue가 실행될 때 증감식이 어떻게 처리되는지 구분.

### 6️⃣ 배열의 한계와 보완 (Fixed Size Limitation)
- 정의: 배열은 선언 시 크기가 고정되어 있어 데이터 추가/삭제가 어려움.
- 원리: 고정된 메모리 할당으로 인한 불편함을 컬렉션 프레임워크(ArrayList)로 보완.
- 예시: List<Integer> list = new ArrayList<>(); // 가변 크기 배열 개념.
- 주의사항: 배열은 메모리 효율이 좋고 빠르지만, 유연성이 부족함을 인지할 것.
- 시험 포인트: 배열의 크기 고정 개념과 동적 할당의 필요성.

### 📊 비교 정리표 2개
| 구분 | for문 | while문 |
| :--- | :--- | :--- |
| 목적 | 반복 횟수가 명확할 때 | 조건에 따라 반복할 때 |
| 구조 | 초기식, 조건식, 증감식 통합 | 조건식만 배치 |
| 용도 | 배열 순회, 수열 연산 | 무한 루프, 사용자 입력 대기 |

| 구분 | 배열 (Array) | 가변 리스트 (ArrayList) |
| :--- | :--- | :--- |
| 크기 | 고정 (Immutable) | 동적 (Mutable) |
| 접근 속도 | 매우 빠름 | 객체 오버헤드로 다소 느림 |
| 사용 | 고정된 데이터 저장 | 데이터 추가/삭제가 잦을 때 |

## 연습 퀴즈

1. Java 배열의 특징으로 옳지 않은 것은?
   A. 배열은 선언과 동시에 크기가 고정된다.
   B. 배열의 인덱스는 0부터 시작한다.
   C. 배열의 길이는 .length 속성으로 확인한다.
   D. 배열은 서로 다른 데이터 타입을 한꺼번에 저장할 수 있다.
   정답: D
   관련 키워드: 배열(Array)의 구조
   해설: 배열은 동일한 자료형의 데이터만 저장할 수 있는 자료구조입니다. 서로 다른 타입을 저장하려면 객체 배열이나 컬렉션을 사용해야 합니다.

2. for문과 while문의 차이점에 대한 설명으로 적절한 것은?
   A. for문은 반드시 무한 루프를 생성한다.
   B. while문은 반복 횟수가 정해져 있을 때 사용하는 것이 원칙이다.
   C. for문은 초기화, 조건식, 증감식을 한 줄에 관리하여 반복 횟수가 명확할 때 유리하다.
   D. 두 문법은 기능적으로 서로 호환될 수 없으며, 완전히 다른 목적을 가진다.
   정답: C
   관련 키워드: 반복문(for, while)
   해설: for문은 제어 요소가 문법 구조 안에 통합되어 있어 횟수가 정해진 반복에 유리합니다. while문은 조건 기반으로 동작하므로 무한 루프나 조건부 반복에 유리합니다.

3. 다음 중 switch문에서 break가 생략될 경우 발생하는 현상은?
   A. 컴파일 에러가 발생한다.
   B. 실행이 중단된다.
   C. 일치하는 케이스 이후의 문장들이 break를 만날 때까지 실행된다.
   D. 해당 케이스만 실행되고 즉시 종료된다.
   정답: C
   관련 키워드: 조건문(if, switch)
   해설: switch문에서 break가 없으면 다음 케이스의 문장들이 연달아 실행되는 fall-through 현상이 발생합니다.

4. 배열의 인덱스 범위를 초과하여 접근할 때 발생하는 예외는?
   A. NullPointerException
   B. ArrayIndexOutOfBoundsException
   C. ArithmeticException
   D. IllegalArgumentException
   정답: B
   관련 키워드: 배열(Array)의 구조
   해설: 선언된 배열의 길이보다 크거나 0보다 작은 인덱스를 참조하려 할 때 발생하는 Java의 대표적인 예외입니다.

5. 반복문에서 '현재 실행 중인 회차를 즉시 중단하고 다음 회차로 넘어가는' 제어 키워드는?
   A. break
   B. continue
   C. return
   D. exit
   정답: B
   관련 키워드: Break와 Continue 제어
   해설: continue는 현재 반복의 남은 코드를 건너뛰고 바로 다음 반복 조건식으로 넘어가게 합니다. break는 루프를 완전히 탈출합니다.
