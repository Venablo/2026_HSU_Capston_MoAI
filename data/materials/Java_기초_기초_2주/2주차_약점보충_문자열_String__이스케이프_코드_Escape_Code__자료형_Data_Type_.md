## 약점 보충 학습

### 🔁 약점 보충 학습 목표
이번 2주차 파이널 퀴즈 결과, 학습자님께서는 Java의 가장 기초적인 데이터 관리 체계인 변수(Variable)와 자료형(Data Type)에서부터, 문자열(String)을 다루는 세부 기법인 이스케이프 코드와 포맷팅 영역에서 다수의 오답을 보였습니다. 특히 정수와 실수 간의 형 변환, 문자열 내 특수문자 처리, 그리고 연산자 우선순위와 포맷 지정자의 혼동이 학습의 발목을 잡고 있습니다. 본 보충 학습은 각 개념의 기술적 원리를 명확히 규명하고, 실무에서 흔히 발생하는 실수를 방지하여 Java 프로그래밍의 견고한 기초를 다지는 데 목적이 있습니다.

### 키워드별 심화 정리

#### 1. 변수(Variable)와 자료형(Data Type)
변수는 데이터를 저장하기 위해 할당된 메모리 공간의 이름입니다. Java는 정적 타이핑(Static Typing) 언어로, 변수 선언 시 자료형을 반드시 명시해야 합니다. 기본형(Primitive Type)인 int, double, boolean 등은 스택(Stack) 메모리에 실제 값을 저장하며, 참조형(Reference Type)인 String 등은 힙(Heap) 메모리의 주소값을 저장합니다. 

*원리*: 자료형은 메모리 크기를 결정합니다. 예를 들어 int는 4바이트, double은 8바이트를 차지합니다. 형 변환(Casting) 시 작은 타입을 큰 타입으로 넣는 자동 형 변환(Implicit Casting)과 반대되는 명시적 형 변환(Explicit Casting)의 원리를 이해해야 데이터 유실을 막을 수 있습니다.
*예시*: `int a = 10; double b = a;`는 가능하지만 `double c = 10.5; int d = (int)c;`는 소수점이 버려지는 명시적 형 변환이 필요합니다.
*자주 하는 실수*: 정수 연산 시 결과값이 소수점이 필요함에도 int형으로 선언하여 소수점이 잘리는 '정수 나눗셈 함정'에 자주 빠집니다.

#### 2. 문자열(String)과 이스케이프 코드(Escape Code)
String은 Java에서 객체(Object)입니다. 리터럴로 생성하면 상수 풀(String Constant Pool)에 저장되어 메모리를 효율적으로 관리합니다. 이스케이프 코드는 문자열 내에서 표현할 수 없는 제어 문자나 특수문자를 역슬래시(\ )를 통해 표현하는 방식입니다.

*원리*: `\n`(줄바꿈), `\t`(탭), `\"`(큰따옴표) 등이 대표적입니다. 문자열 내에서 큰따옴표를 쓰고 싶을 때 그냥 입력하면 컴파일러는 문자열의 끝으로 인식하므로 이스케이프 코드가 필수적입니다.
*예시*: `System.out.println("Hello \"Java\" World");`는 출력 결과에 큰따옴표를 포함시킵니다.
*자주 하는 실수*: 역슬래시(\ )의 방향을 반대(/)로 적거나, 경로 문자열(File Path) 작성 시 역슬래시를 이스케이프 문자로 인식하여 발생하는 오류가 빈번합니다.

#### 3. 연산자(Operator)
연산자는 데이터를 연산하고 처리하는 도구입니다. 산술, 비교, 논리, 대입 연산자로 나뉩니다. 특히 증감 연산자(++, --)의 전위/후위 방식은 연산 순서에 결정적 차이를 만듭니다.

*원리*: 연산자 우선순위(Operator Precedence)에 따라 식의 결과가 달라집니다. 단항 연산자 > 산술 연산자 > 비교 연산자 > 논리 연산자 순입니다.
*예시*: `int x = 5; int y = x++;`에서 y는 5가 되고 x는 6이 됩니다. 하지만 `y = ++x;`라면 y는 6이 됩니다.
*자주 하는 실수*: 논리 연산자 `&&`(AND)와 `||`(OR)의 단락 평가(Short-circuit Evaluation) 원리를 간과하여 예상치 못한 코드 실행 결과(예: 뒤의 식이 실행되지 않음)를 얻는 경우가 많습니다.

#### 4. 포맷팅(Formatting)
문자열 내에 데이터를 특정 형식으로 삽입하는 기술입니다. `String.format()`이나 `System.out.printf()`를 사용합니다.

*원리*: 서식 지정자(Specifier)를 사용합니다. `%d`(정수), `%f`(실수), `%s`(문자열) 등이 있으며, `%5.2f`처럼 전체 너비와 소수점 자릿수를 지정할 수 있습니다.
*예시*: `System.out.printf("값: %.2f", 3.14159);`는 '값: 3.14'를 출력합니다.
*자주 하는 실수*: 서식 지정자 타입과 실제 변수의 자료형을 불일치시키는 경우(예: `%d`에 실수 넣기) 발생합니다.

### 비교 정리표

| 구분 | 변수(Variable) | 자료형(Data Type) | 문자열(String) | 이스케이프 코드 | 포맷팅(Formatting) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **핵심 역할** | 데이터 저장 공간 | 데이터 성격 규정 | 텍스트 데이터 관리 | 특수 문자 표현 | 출력 형태 제어 |
| **분류** | - | 기본형/참조형 | 참조형(객체) | 특수 문자 상수 | 출력 함수/메서드 |
| **메모리 위치** | 스택/힙 | - | 힙(상수 풀) | - | - |

### 핵심 암기 포인트 & 체크리스트

- [ ] **증감 연산자 체크**: `x++`는 사용 후 증가, `++x`는 증가 후 사용임을 명심하십시오.
- [ ] **문자열 비교**: 문자열은 `==`이 아닌 `.equals()` 메서드로 값을 비교해야 합니다.
- [ ] **이스케이프 규칙**: 윈도우 파일 경로 `C:\Users`는 Java에서 `"C:\\Users"`로 써야 함을 기억하십시오.
- [ ] **형 변환**: `(double) intValue`와 같이 명시적 변환이 필요한 경우를 항상 체크하십시오.
- [ ] **정수 나눗셈**: `5 / 2`는 `2.5`가 아닌 `2`입니다. `5.0 / 2`로 표현해야 실수 결과가 나옵니다.
- [ ] **포맷팅**: 서식 지정자 `%s`, `%d`, `%f`의 용도를 완벽히 숙지하십시오.
