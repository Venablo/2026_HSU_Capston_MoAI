## 약점 보충 학습

### 🔁 약점 보충 학습 목표
이번 2주차 파이널 퀴즈에서 학습자님은 Java의 기초 문법을 구성하는 데이터 처리 및 제어 단위에서 일부 혼선을 겪으셨습니다. 특히 원시 자료형(Primitive Data Type)과 참조 자료형(Reference Data Type)의 메모리 관리 차이, 그리고 컬렉션 프레임워크인 리스트(List)의 동적 제어 방식과 문자열 조작 시 인덱싱 및 슬라이싱 범위를 다루는 데 어려움이 있었습니다. 본 학습 자료는 단순히 문법을 암기하는 것을 넘어, 컴퓨터의 메모리 관점에서 이 개념들이 어떻게 작동하는지 이해하고, 실무에서 흔히 발생하는 예외 상황(Exception)을 방지하는 능력을 기르는 것을 목표로 합니다.

### 키워드별 심화 정리

**1. 자료형(Data Type) 및 변수(Variable)**
정의: 자료형은 데이터의 종류와 크기를 정의하며, 변수는 그 데이터를 담는 메모리 공간의 이름입니다. Java는 정적 타이핑(Static Typing) 언어로, 변수 선언 시 자료형을 반드시 명시해야 합니다.
원리: Java의 자료형은 기본형(int, double, boolean 등)과 참조형(String, List 등)으로 나뉩니다. 기본형은 스택(Stack) 메모리에 실제 값을 저장하지만, 참조형은 힙(Heap) 메모리의 주소값을 저장합니다.
예시: `int age = 25;`는 4바이트 공간에 25를 할당하고, `String name = "MoAI";`는 힙에 문자열을 저장하고 `name` 변수는 그 주소를 가리킵니다.
자주 하는 실수: 참조형 변수를 초기화하지 않고 사용할 때 발생하는 `NullPointerException`과, 변수의 유효 범위(Scope)를 벗어나서 접근하려는 시도가 빈번합니다.

**2. 문자열(String), 이스케이프 코드(Escape Code), 포맷팅(Formatting)**
정의: String은 불변(Immutable) 객체로 문자들의 집합입니다. 이스케이프 코드는 특수 문자를 표현하며, 포맷팅은 문자열을 규격화합니다.
원리: String은 한번 생성되면 변경할 수 없습니다. 문자열 내 줄바꿈(`\n`), 탭(`\t`) 같은 이스케이프 코드는 제어 문자를 포함하는 방식입니다. 포맷팅은 `String.format()`이나 `printf`를 사용하여 특정 형식(지정자)에 맞게 데이터를 삽입합니다.
예시: `System.out.printf("이름: %s, 나이: %d", "홍길동", 20);`와 같이 사용합니다.
자주 하는 실수: String을 변경할 때마다 새로운 객체가 생성된다는 점을 간과하여, 반복문 내에서 `+` 연산자로 문자열을 계속 더하는 비효율적인 코드를 작성하는 경우가 많습니다.

**3. 리스트(List), 인덱싱(Indexing), 슬라이싱(Slicing), 리스트 함수(List Function)**
정의: List는 순서가 있고 중복을 허용하는 인터페이스(구현체: ArrayList)입니다. 인덱싱은 특정 위치의 값을 가져오고, 슬라이싱은 부분 리스트를 추출하는 작업입니다.
원리: 인덱스는 0부터 시작합니다. Java는 파이썬처럼 문법적인 슬라이싱 연산자(`[:]`)가 없으므로 `subList(fromIndex, toIndex)` 메서드를 사용합니다. 이때 `toIndex`는 포함되지 않는(Exclusive) 점을 주의해야 합니다.
예시: `List<Integer> list = new ArrayList<>(); list.add(10);` 이후 `list.get(0)`으로 접근합니다.
자주 하는 실수: 리스트의 크기를 벗어난 인덱스에 접근하여 `IndexOutOfBoundsException`을 발생시키는 것과, `subList`가 원본 리스트의 뷰(View)를 반환한다는 점을 잊고 원본을 변형하는 것입니다.

### 비교 정리표

| 구분 | 기본 자료형(Primitive) | 참조 자료형(Reference) | 특징 |
| :--- | :--- | :--- | :--- |
| 메모리 | Stack | Heap | 효율성 vs 확장성 |
| 초기값 | 기본값 존재(0, false) | null | Null 안전성 |
| 메서드 | 없음 | 제공됨(String, List 등) | 기능성 차이 |

| 작업 항목 | 개념 | 핵심 주의사항 |
| :--- | :--- | :--- |
| 인덱싱 | 단일 요소 접근 | 0부터 시작, 크기 초과 주의 |
| 슬라이싱 | 부분 리스트 추출 | 종료 인덱스는 제외됨(Exclusive) |
| 포맷팅 | 출력 규격 지정 | `%s`, `%d`, `%f` 지정자 숙지 |

### 핵심 암기 포인트 & 체크리스트

**[핵심 암기 포인트]**
1. **String은 Immutable(불변)**: 문자열 수정 시 기존 객체가 바뀌는 것이 아니라 새로운 객체가 만들어짐.
2. **List.subList(start, end)**: start는 포함, end는 미포함.
3. **Escape Code**: 역슬래시(`\`)로 시작하며, `\n`(개행), `\t`(탭), `\\`(역슬래시 자체)는 필수 암기.
