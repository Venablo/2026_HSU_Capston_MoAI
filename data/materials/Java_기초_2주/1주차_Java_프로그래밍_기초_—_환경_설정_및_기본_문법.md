## 마크다운 학습 자료 — Java 프로그래밍 기초

### 📌 이번 주차 전체 지도
이번 주차는 Java의 핵심 구동 원리인 JVM을 이해하는 것으로 시작하여, 데이터를 다루는 그릇인 변수와 자료형, 그리고 프로그램의 흐름을 결정하는 연산자와 제어문을 학습합니다. 이는 2주차에 배울 객체지향 프로그래밍(OOP)의 데이터를 저장하고 가공하는 최소 단위가 되므로, 각 개념의 정확한 활용법을 익히는 것이 중요합니다. 학습 순서는 개발 환경 설정 -> 변수/자료형 개념 -> 연산자 활용 -> 제어문(조건/반복) 실습 순으로 진행합니다.

### 1️⃣ JVM과 컴파일 원리
- 정의: JVM(Java Virtual Machine)은 작성된 바이트코드(.class)를 운영체제 환경에 맞춰 실행해주는 가상 머신입니다.
- 원리: 컴파일러(javac)가 소스 코드(.java)를 바이트코드로 변환하고, JVM이 이를 해석하여 기계어로 변환합니다.
- 예시: Windows에서 작성한 코드가 Linux에서도 동일하게 동작하는 'Write Once, Run Anywhere'의 핵심입니다.
- 주의사항: JDK(개발 도구)와 JRE(실행 도구)의 차이를 명확히 인지해야 합니다.
- 시험 포인트: JVM이 OS와 Java 프로그램 사이의 '중재자'임을 기억하세요.

### 2️⃣ 변수(Variable)와 자료형(Data Type)
- 정의: 데이터를 메모리에 저장하기 위한 이름이 붙은 공간입니다.
- 원리: 자료형에 따라 메모리 할당 크기가 결정되며, 타입에 맞는 값을 저장해야 데이터 손실이 없습니다.
- 예시: 정수(int), 실수(double), 문자열(String), 논리형(boolean).
- 주의사항: 초기화되지 않은 변수는 사용할 수 없습니다.
- 시험 포인트: 기본 자료형(Primitive)과 참조 자료형(Reference)의 구분.

### 3️⃣ 문자열(String)과 포맷팅
- 정의: 텍스트 데이터를 처리하는 객체 자료형입니다.
- 원리: 불변(Immutable) 객체로, 변경 시 새로운 객체가 생성됩니다.
- 예시: System.out.printf("%d %s", 10, "Java");
- 주의사항: String 비교는 '==' 연산자가 아닌 equals() 메소드를 사용해야 합니다.
- 시험 포인트: String.format()을 이용한 문자열 생성 방식.

### 4️⃣ 연산자(Operator)
- 정의: 변수의 값을 연산하거나 제어 흐름을 결정하는 기호입니다.
- 원리: 산술(+,-,*,/,%), 비교(>, <, ==), 논리(&&, ||) 등으로 나뉩니다.
- 예시: x % 2 == 0 은 짝수 판별의 공식입니다.
- 주의사항: 나눗셈 연산 시 정수/정수는 정수를 반환함을 유의하세요.
- 시험 포인트: 논리 연산자의 단축 평가(Short-circuit Evaluation).

### 5️⃣ 조건문(if-else, switch)
- 정의: 특정 조건의 참/거짓에 따라 실행 흐름을 분기합니다.
- 원리: 불리언(Boolean) 값을 평가하여 코드를 건너뛰거나 실행합니다.
- 예시: 점수에 따른 학점(A, B, C) 부여.
- 주의사항: switch 문 사용 시 break;를 빠뜨리면 다음 케이스까지 실행됩니다.
- 시험 포인트: 중첩 if문의 가독성 유지 전략.

### 6️⃣ 반복문(for, while)
- 정의: 동일한 작업을 특정 횟수만큼 반복 수행합니다.
- 원리: 반복 범위가 정해져 있을 땐 for문, 조건에 따라 반복할 땐 while문을 주로 사용합니다.
- 예시: 구구단 2단 출력.
- 주의사항: 무한 루프에 빠지지 않도록 탈출 조건을 반드시 설정해야 합니다.
- 시험 포인트: for문의 증감식 활용법.

### 📊 비교 정리표
| 비교항목 | 기본 자료형(Primitive) | 참조 자료형(Reference) |
| :--- | :--- | :--- |
| 데이터 저장 | 실제 값을 스택에 저장 | 메모리 주소를 스택에 저장 |
| 종류 | int, double, boolean 등 | String, 배열, 클래스 등 |

| 비교항목 | for문 | while문 |
| :--- | :--- | :--- |
| 용도 | 반복 횟수가 정해진 경우 | 조건 만족 시까지 반복할 경우 |
| 특징 | 초기식, 조건식, 증감식이 한 곳에 위치 | 조건식만 명시하여 구조가 간결함 |

## 연습 퀴즈

1. Java에서 String 객체의 값을 비교하는 가장 올바른 방법은?
   A. str1 == str2
   B. str1.equals(str2)
   C. str1.compare(str2)
   D. str1.match(str2)
   정답: B
   관련 키워드: 문자열(String)
   해설: Java에서 ==는 주소값을 비교하지만, equals()는 문자열 내부의 실제 텍스트 내용을 비교합니다.

2. 다음 중 JVM의 역할로 적절하지 않은 것은?
   A. 바이트코드를 기계어로 변환
   B. 가비지 컬렉션(GC)을 통한 메모리 관리
   C. 운영체제에 독립적인 실행 환경 제공
   D. 소스 코드를 직접 컴파일하여 파일 생성
   정답: D
   관련 키워드: JVM
   해설: 소스 코드를 컴파일하는 것은 컴파일러(javac)의 역할이며, JVM은 컴파일된 바이트코드를 해석/실행합니다.

3. 기본 자료형(Primitive Type)에 해당하지 않는 것은?
   A. int
   B. boolean
   C. String
   D. double
   정답: C
   관련 키워드: 자료형(Data Type)
   해설: String은 클래스로 정의된 참조 자료형입니다. 나머지는 언어 자체에서 제공하는 기본 자료형입니다.

4. 반복문에서 특정 조건일 때 반복을 즉시 중단하는 키워드는?
   A. break
   B. continue
   C. return
   D. stop
   정답: A
   관련 키워드: 반복문
   해설: break는 현재 실행 중인 반복문을 완전히 빠져나옵니다. continue는 다음 반복으로 넘어갑니다.

5. 정수 5 나누기 2의 결과는 무엇인가?
   A. 2.5
   B. 2
   C. 3
   D. 2.0
   정답: B
   관련 키워드: 연산자
   해설: Java에서 정수와 정수의 연산은 정수형으로 반환되므로 소수점은 절삭되어 2가 됩니다.

## 주차 과제

제목: 기초 연산 프로그램 제작

사용자로부터 숫자 2개를 입력받아 사칙연산을 수행하고 결과를 출력하는 간단한 Java 프로그램을 작성하세요.

[제출 체크리스트]
- Scanner 클래스를 사용하여 사용자 입력 받기
- 산술 연산자 (+, -, *, /) 사용
- 결과값을 포맷팅을 사용해 깔끔하게 출력
- 0으로 나눌 경우 예외 처리(if 문)

[필수 키워드] 자료형(Data Type), 변수(Variable), 조건문(if-else), 연산자(Operator)

[수행 단계]
1. Scanner 객체 생성 및 두 수 입력
2. if문으로 나누기 연산 시 분모가 0인지 체크
3. 결과를 printf로 출력

[채점 기준] 정확한 연산 결과 + 조건문 활용(0 나누기 방지) + 올바른 자료형 사용
[배점] 100점
